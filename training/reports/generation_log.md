# سجل توليد الداتا سيت (generation_log)

> **ملاحظة أمانة:** هذا السجل يوثّق ما هو **مثبت فعلياً** في `training/training_notebook.ipynb`
> وما يمكن التحقق منه من الملف الناتج. القيم غير المتوفرة (عدد الاستدعاءات الفعلي، استهلاك التوكنز)
> **لم تُسجَّل** أثناء التشغيل على Colab، وهي مُعلَّمة صراحةً كـ «غير متوفر» بدل تخمينها.

## 1) الجهة والمزوّد

| البند | القيمة |
|---|---|
| مزوّد الـ LLM | CommandCode API |
| الـ endpoint | `https://api.commandcode.ai/provider/v1/chat/completions` |
| الموديل | `deepseek/deepseek-v4.1-flash` |
| temperature | `1.0` |
| إدارة المفتاح | من Colab Secrets / متغير بيئة / `getpass` — لا يُكتب المفتاح في الكود |

## 2) البرومبت المستخدم (منقول حرفياً من النوتبوك)

**GENERATION_SYSTEM_PROMPT (النظام):**

```
أنت مولّد بيانات تدريب لنموذج NLP. مهمتك إنشاء رسائل واتساب واقعية
يكتبها عملاء عرب (لهجة خليجية/يمنية عامية) لمتجر إلكتروني، لغرض تدريب نموذج تصنيف نصوص.

قواعد صارمة يجب اتباعها:
1. اكتب باللهجة العامية الحقيقية فقط، ممنوع الفصحى الرسمية.
2. أدخل أخطاء إملائية طبيعية كما يكتبها الناس فعلاً على الجوال (حذف همزات، دمج كلمات، أخطاء شائعة).
3. نوّع طول الرسائل (بعضها سطر واحد، بعضها عدة أسطر).
4. لا تكرر نفس الصياغة أو نفس الجمل الافتتاحية بين الرسائل.
5. أرجع الإخراج **بصيغة JSON فقط** بدون أي نص إضافي قبله أو بعده، على شكل:
{"messages": ["رسالة 1", "رسالة 2", ...]}
```

**قالب رسالة المستخدم `build_user_prompt`:**

```
المطلوب: ولّد {n} رسائل عميل مختلفة تماماً عن بعضها.
الفئة المطلوبة: {category_desc}
شخصية الكاتب المطلوبة لهذه الدفعة: {persona}
المنتج المذكور (اذكره بصيغة طبيعية داخل بعض الرسائل، وليس بالضرورة كلها): {product}
تذكر: أرجع JSON فقط بالصيغة المحددة، بدون أي شرح إضافي.
```

## 3) مدخلات التوليد (من النوتبوك)

- **الفئات (4)**: `complaint` (شكوى)، `order_inquiry` (استفسار عن طلب)، `return_request` (طلب استرجاع)، `other` (أخرى).
- **المنتجات (15)**: سماعة بلوتوث، شاحن سريع، ساعة ذكية، جوال سامسونج، لابتوب ديل، طقم مطبخ، مكواة بخار، مكنسة كهربائية، كرسي مكتب، طاولة قهوة، حذاء رياضي، شنطة ظهر، نظارة شمسية، عطر رجالي، بطانية شتوية.
- **الأنماط الشخصية (6)**: عصبي/مستعجل، مهذب ومفصّل، مقتضب، يستخدم إيموجي، يخلط إنجليزية بسيطة، كبير بالسن بأسلوب تقليدي.
- **إعدادات الدفعات**: `BATCH_SIZE = 5`، `TARGET_PER_CATEGORY = 1000`، فاصل `time.sleep(0.5)` بين الاستدعاءات.

## 5) الاستدعاءات والتكلفة

- **عدد الاستدعاءات الفعلي: غير متوفر** — لم يُسجَّل أثناء تشغيل Colab.
  - تقدير تقريبي فقط (غير مؤكد): إذا أعاد كل استدعاء 5 رسائل، فالحد الأدنى ≈ 800 استدعاء لـ 4000 رسالة.
- **استهلاك التوكنز / التكلفة التقريبية: غير متوفر** — لم يُسجَّل أثناء التشغيل.
- **المطلوب من صاحب المشروع**: إن كان سجل Colab متاحاً، يُفضَّل تزويد عدد الاستدعاءات الفعلي واستهلاك التوكنز لتحديث هذا الملف بقيم حقيقية.

## 6) ملاحظات

- النوتبوك يطبّق التطبيع (`normalize_arabic`) **بعد** حفظ `raw_dataset.csv`، لذلك الملف الخام يحتوي النص غير المطبّع (وهذا مقصود).
- النوتبوك يستخدم لهجة «خليجية/يمنية عامية» في برومبته؛ اللهجة المهيمنة المتفق عليها للمشروع هي **اليمنية**، والداتا تُظهر مزيجاً عامياً واقعياً.
